# Spotify Web Player Clone

A web-based music player inspired by Spotify. Browse albums and songs, play/pause music, control volume, and navigate tracks. Built with HTML, CSS, and JavaScript.

---

## Features

- Browse albums and songs dynamically
- Play, pause, skip, and previous track controls
- Seek bar for tracking song progress
- Volume control
- Responsive sidebar with Home, Search, and Library
- Dynamic song list rendering
